# 搜索聚焦主题 + 快捷导航分区

日期：2026-09-08  
状态：approved

## Goal

1. 搜索框 `:focus` 样式跟随浅色 / 深色 / 高对比主题。
2. 快捷导航页分为「推荐导航点」与「历史导航点」（方案 C）。

## Non-goals

- 推荐点在线拉取 / 设置页增删
- 收藏夹独立模块

## 搜索聚焦

- 背景 / 边框 / 光晕使用主题变量（`--paper`、`--navy`、`--ink`）
- 深色不再写死白底；高对比加粗描边

## 快捷导航

- 推荐：`src/lib/recommendPlaces.js` 固定配置
- 历史：现有 `navHistory`；清空只清历史
- 点选任一项 → 回首页 `applyHistoryItem`
