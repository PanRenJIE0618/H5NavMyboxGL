# H5NavMyBoxGL · 现场定位

基于 **Vue 3 + Vite + Mapbox GL** 的 H5 现场定位与导航应用。底图与检索、驾车规划对接 **天地图**，目标坐标系为 **WGS84**（适配 Mapbox）。

---

## 功能概览

### 地图与定位

- 天地图底图：矢量 / 影像 / 地形（可切换，本地持久化）
- 浏览器定位（`Geolocation`），按 UA 适配超时与轮询；双重验证坐标内核（WGS84 / GCJ-02），减少乱纠偏
- 自定义定位标（脉冲、朝向针、「我的位置」）
- 设备朝向（罗盘 / 航向），支持朝向锁定转地图
- 实时测速（km/h），可配置限速与超速提示
- 2D / 3D 俯仰切换

### 搜索与路线

- 地址 / 地点关键词搜索（天地图检索 + 地理编码兜底）
- 出行方式：**驾车**、**步行**
- 驾车：**最快 / 最短** 双方案预览与切换
- 步行：起终点直线示意 + 步行时速估时
- 选点落标、路线绘制（主线 / 备选、描边、箭头）

### 导航过程

- 一键导航或先预览再开始
- 剩余里程 / 时间、下一路口引导、剩余路程进度条
- 路线吸附与视角跟随（可选自动视角锁定）
- 偏航监测与重规划（策略可配）；到达判定
- 拖图后短暂暂停跟随，空闲后按设置自动回锁
- 导航中隐藏底部 Tab，避免误切页

### 语音播报

- Web Speech（中文）播报开导概览、引导、偏航、到达等
- 需用户手势解锁（移动端尤其重要）
- 「我的」总开关 + 地图侧静音按钮，偏好本地持久化

### 快捷导航

- **常去地点**：结束导航后按目的地累计，满 2 次起显示，可单条删除
- **推荐导航点**（可配置）：如天安门、北京西站、南站、机场 T3、三里屯等
- **历史导航点**：结束导航后写入，可单条删除 / 清空
- 点选后回到首页并设为目的地，便于继续规划

### 会话恢复

- 刷新或进程被杀后，若有未完成导航（默认 2 小时内），提示「继续导航 / 放弃」
- 回前台时重绑定位与语音相关状态

### 剪贴板地址

- 监测剪贴板文本（需 HTTPS + 浏览器剪贴板权限）
- 识别地址 / 地名 / 经纬度后提示「前往并导航」
- 确认后：搜点 → 规划 → 直接开导；可忽略（同内容不再弹）
- Chrome 等浏览器：授权后回到页面**点一下**通常更易读到剪贴板

### 「我的」设置

- **语言**：简体中文（默认）/ English / 繁體中文；同时切换界面文案与语音播报语言
- **导航行为**：自动视角锁定、语音播报、默认出行方式、默认路线偏好
- **外观**：浅色 / 深色 / 高对比（深色同步暗色矢量底图）
- **底图**：矢量 / 影像 / 地形
- **存储**：查看本地/会话占用，单项清理、清理导航数据、清空全部；可恢复默认设置
- **本机信息**：浏览器、设备名、系统、坐标系、定位方案、屏幕与能力摘要等（不含账号与安全策略细节）

### 其它

- 底部三 Tab：**首页** | **快捷导航** | **我的**；页面切换与浮层开合带动画
- 微信内非正式 HTTPS 环境拦截提示，可复制打开链接
- 标题旁「日志」调试控制台（定位相关）

## 快速开始

### 环境要求

- Node.js（建议 LTS）
- 手机定位需 **HTTPS**（或本机 `localhost`）

### 配置

在项目根目录 `.env` 中配置天地图密钥：

```env
VITE_TIANDITU_TK=你的天地图密钥
```

### 命令

```bash
npm install
npm run dev      # 开发：HTTPS，默认 https://主机:5173/
npm run build    # 构建产物输出到 build/
npm run preview  # 预览构建结果
```

开发服已启用自签证书与局域网可访问（`host: true`）。手机访问时用同一局域网的 `https://你的IP:5173/`，证书提示选择继续访问，并允许定位 / 朝向 / 剪贴板等权限。

## 本地偏好键（摘要）

| 键 | 用途 |
| --- | --- |
| `h5nav:uiTheme` | 界面主题 |
| `h5nav:locale` | 界面与语音语言 |
| `h5nav:basemap` | 底图类型 |
| `h5nav:navPrefs` | 语音、默认出行、默认路线 |
| `h5nav:autoViewLock` | 自动视角锁定 |
| `h5nav:navHistory` | 导航历史 |
| `h5nav:frequentPlaces` | 常去地点 |
| `h5nav:session` | 未完成导航会话（`sessionStorage`） |

行为阈值（到达距离、偏航、测速限速等）见 `src/config/behaviorPolicy.js`，支持运行时热更新。

## 说明与限制

- 步行路线当前为直线示意，非完整步行路网。
- 剪贴板能力依赖浏览器权限与安全上下文；部分环境需用户手势后才能读取。
- 微信内打开请使用可信任的正式 HTTPS 域名；本机 / 局域网调试请用系统浏览器。
- 地图与业务坐标以 **WGS84** 为目标系，与 Mapbox 默认一致。
